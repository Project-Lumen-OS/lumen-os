# Lumen OS on the XGIMI X50 Ultra: the MediaTek / XGIMI files the image takes at boot from the user's own
# z9x_blobs partition (16 MiB on this projector). Hashes only; the files themselves are proprietary and are never
# in git or in an image. The installer copies them from the user's own stock (or Lumen OS) system with adb and
# refuses any file whose sha256 is not listed here.
# Image path /system/etc/z9x/x50_blobs_allow.txt (read by /system/etc/z9x/x50_blobs.sh); installer copy
# installer/lib/x50/blobs_allow.txt (identical).
#   - the nine codec / audio files of the Z9X set z9x-v61558-b: the X50 stock v1.2.64 copies have the very same
#     sha256 (gsi-research/X50_PORT_LOG.md), so these lines are the Z9X lines unchanged;
#   - need=eye: the stock eye-protection drawer /system/bin/nativeui (it draws the person-shaped black mask of
#     eye protection mode 0 when the vendor asks for it) and the one library it links that
#     the Lumen system does not have. All or nothing: x50_blobs.sh binds and starts nativeui only when every
#     need=eye line is there with its sha256, and the installer never builds a partition without them.
#
# set=<id> names this exact file set (sys.z9x.blobs.set).
# <sha256> <path inside the blobs tar> <stock source path> [option ...]
#   path       image path relative to /system/: x50_blobs.sh binds the file over that 0-byte placeholder,
#   bind=      or, when given, over this vendor / VNDK APEX file instead (no placeholder),
#   from=      the installer may derive the file from the stock file at <stock source path> with that
#              sha256 by deleting lines (sed 'N,Md' commands only), then checks <sha256> as usual,
#   label=     the SELinux type of the bound file instead of system_file / system_lib_file (only
#              nativeui_main_exec: the vendor policy's typetransition init -> nativeui_main),
#   mode=      0755 for the executable (default 0644),
#   need=eye   eye protection: all of these lines or none of them; the installer has no way around them.
#   alt=       <firmware>:<sha256>: the copy of another XGIMI stock firmware (ro.vendor.build.version.incremental),
#              accepted as it is only while that firmware's vendor runs (the image's x50_blobs.sh, the in-trial
#              installer, the computer installer); the need=eye files are all base copies or all that firmware's.
#              v1.2.54 (gsi-research/X50_FW_1254_RU.md): the nine codec / audio sources are byte-equal to v1.2.64,
#              only the eye-protection pair differs.
# The installer pulls <stock source path> first, then /system/<path>.
