# Установка Lumen OS

[English version](en.md)

Lumen OS можно поставить двумя способами:

- [Простая установка](#easy): прямо с проектора, приложением Lumen Installer. Без компьютера и без кабеля.
- [Для опытных](#advanced): с компьютером. Для Play 6 и для случаев, которые приложение не покрывает.

| Проектор | Простая установка | Для опытных |
|---|---|---|
| XGIMI Z9X (G0082) | проба и установка на прошивке XGIMI V6.15.58 или V6.15.62, только проба на V6.15.19 | [инструкция для Z9X](z9x/ru.md) |
| XGIMI Z9X HB (G0130, G0148) | проба стабильной версии, проба и установка беты. G0130 на V6.16.24 или V6.17.12, G0148 на V6.17.12 | [инструкция для Z9X HB](hb/ru.md) |
| XGIMI X50 Ultra (G0111), X50 Ultra Max (G0100) | только проба, бета. Прошивка XGIMI V1.2.64 или V1.2.54 | нет |
| XGIMI Play 6 (G0058) | нет | [инструкция для Play 6](play6/ru.md), прошивка XGIMI V1.7.116 или V1.8.127 |

Модель и прошивку XGIMI вашего проектора Lumen Installer показывает в разделе «О программе» (круглая «i»).

<a name="easy"></a>

## Простая установка: с проектора

Нужны проектор на системе XGIMI с интернетом, флешка и свободное место в памяти проектора. Сколько места нужно,
приложение скажет само.

1. Скачайте из [последнего релиза](https://github.com/Project-Lumen-OS/lumen-installer/releases/latest) файл Lumen Installer с окончанием `.apk1`
   и скопируйте его на флешку (FAT32 или exFAT).
2. Вставьте флешку в проектор, откройте файл в файловом менеджере XGIMI и подтвердите установку.
3. Откройте Lumen Installer. Он узнаёт модель, находит её в подписанном списке поддерживаемых проекторов и
   скачивает Lumen OS именно для этой модели. Перед использованием каждый файл проверяется по подписи. На
   Z9X HB можно выбрать «Версия: стабильная» или «Версия: бета».
4. Сначала попробуйте: «Подготовить пробный запуск», потом «Запустить Lumen OS». Lumen OS запустится один раз,
   из файлов в памяти проектора. Система XGIMI и ваши файлы остаются как есть. Чтобы вернуться, просто
   перезапустите проектор.
5. Чтобы оставить Lumen OS, откройте внутри пробного запуска «Установить Lumen OS» и выберите, нужны ли сервисы
   Google (Play Маркет, YouTube и ваш аккаунт Google, около 400 МБ с их официальной страницы). Установка один
   раз стирает всё на проекторе: приложения, аккаунты, настройки и файлы. Это займёт около 10 минут. Не
   отключайте проектор от сети.
6. Потом запустится Lumen OS и её настройка. Новые версии приходят по Wi-Fi. Если Lumen OS когда-нибудь не
   запустится, проектор сам вернётся к системе XGIMI.

Там, где установка насовсем пока закрыта (X50, стабильная версия для HB, Z9X на V6.15.19), пробный запуск всё
равно работает, и приложение об этом скажет.

## Для опытных: с компьютером

Установщик для компьютера работает на macOS и Linux. Версия для Windows есть, но ещё не проверялась. Он нужен:

- для Play 6: приложение его пока не поддерживает.
- чтобы установить насовсем там, где приложение даёт только пробу: стабильная версия для HB, Z9X на V6.15.19.
- для ремонта, см. «Если что-то пошло не так» в каждой инструкции.

В каждой инструкции все шаги, сервисы Google, обновления, «Если что-то пошло не так» и «Откат на сток»:
[XGIMI Z9X](z9x/ru.md), [XGIMI Z9X HB](hb/ru.md), [XGIMI Play 6](play6/ru.md).

<a name="google"></a>

## Сервисы Google

Lumen OS ставится без Google. При простой установке ответьте «Да» на вопрос про сервисы Google. С компьютером
см. раздел про Google в инструкции для [Z9X](z9x/ru.md#google), [Z9X HB](hb/ru.md#hb-google) или
[Play 6](play6/ru.md#play6-google). Chromecast built-in в них нет, [почему](z9x/ru.md#chromecast).

<a name="updates"></a>

## Обновления

На Z9X и Z9X HB Lumen OS обновляется сама по Wi-Fi и сохраняет данные, см. [«Обновления»](z9x/ru.md#updates).
На Play 6 новая версия ставится установщиком с компьютера, данные сохраняются, см.
[инструкцию для Play 6](play6/ru.md).

<a name="problems"></a><a name="rescue"></a>

## Если что-то пошло не так

- Во время пробного запуска перезапустите проектор: он вернётся к системе XGIMI. Чтобы освободить место,
  удалите пробный запуск в Lumen Installer.
- Когда просите помощи, приложите то, что Lumen Installer показывает в «О программе», «Подробности для помощи».
- Google не пускает в аккаунт: см. инструкцию для [Z9X](z9x/ru.md#gsf), [Z9X HB](hb/ru.md#hb-gsf) или
  [Play 6](play6/ru.md#play6-gsf).
- С компьютером: «Если что-то пошло не так» для [Z9X](z9x/ru.md#problems), [Z9X HB](hb/ru.md#hb-problems) и
  [Play 6](play6/ru.md#play6-problems).

Спрашивайте в [Telegram-канале](https://t.me/projector_lumenos) или в
[issues на GitHub](https://github.com/Project-Lumen-OS/lumen-os/issues).

<a name="stock"></a>

## Откат на сток

- Во время пробного запуска: перезапустите проектор.
- После установки с проектора: откройте приложения в Lumen OS и выберите «Вернуться к системе XGIMI». Всё в
  Lumen OS при этом сотрётся.
- Всегда: официальная прошивка XGIMI с флешки. Это стирает всё, см. «Откат на сток» для [Z9X](z9x/ru.md#stock),
  [Z9X HB](hb/ru.md#hb-stock) и [Play 6](play6/ru.md#play6-stock).
- X50 Ultra и X50 Ultra Max: пробный запуск систему XGIMI не меняет. Ссылки на прошивку XGIMI есть в описании
  релиза для [X50 Ultra](https://github.com/Project-Lumen-OS/lumen-os/releases/tag/x50-1.0.10-beta3) и
  [X50 Ultra Max](https://github.com/Project-Lumen-OS/lumen-os/releases/tag/x50max-1.0.10-beta3).
