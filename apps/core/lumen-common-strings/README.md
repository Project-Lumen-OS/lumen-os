# lumen-common-strings

The shared vocabulary of Lumen: texts that several apps show, translated once into all 17 locales
(`res/values*/lumen_strings.xml`, keys `lumen_*`). Generated by `python3 tools/i18n/catalog.py module` from
`vocabulary.tsv`, which names for every key the app and key whose translations it takes, byte for byte. Until the
1.1 seam (owner decision D4) the sources are the frozen Z9X apps; when they adopt the vocabulary themselves, the
generated files become the source and `vocabulary.tsv` keeps the provenance.

An app uses it with `module lumen-common-strings` in its recipe and `python3 tools/i18n/catalog.py adopt <App>`:
every string of `res/values/` whose English equals a vocabulary text becomes an alias
(`<string name="section_focus">@string/lumen_focus</string>`), and its copies in `res/values-*/` go. The code keeps its
own keys (and so its own context); the translation exists once. `catalog.py adopt <App> --check` fails when the app
keeps a copy of a vocabulary text; `catalog.py validate` checks the module and every alias.

A new text: reuse a vocabulary key when the English AND the grammatical context match; otherwise add a row whose
source has all 17 locales (or translate it in its own app first, clean-room, all 17 locales). `catalog.py report APP`
lists the reuse candidates of an app.
