# lumen-common-strings

The shared string module of Lumen: every text that two places show (two apps, an app and a core module, two keys of
one module) is defined here once, in English and all 17 locales (`res/values*/lumen_strings.xml`, keys `lumen_*`).
English is `res/values/lumen_strings.xml`; the locales are generated by `python3 apps/i18n/gen.py --write --only strings`
from `apps/i18n/langs/<locale>.txt`, section `@strings/lumen_strings.xml` (one source per text and language).

Every other place keeps its own key, so its code and layouts do not change, as an alias in `res/values/` only:
`<string name="section_focus">@string/lumen_focus</string>`. Its recipe names `module lumen-common-strings`, a core
module that holds an alias names it in `depends=`.

- `python3 tools/i18n/share.py check` (tools/devices/check.sh, tools/arch/suites.sh): fails when one English text is
  defined in two places, unless `known_dups.tsv` names exactly those places with the reason (translations that
  differ, an app with English and Russian only, an app built without a recipe). The list only shrinks.
- `python3 tools/i18n/share.py apply`: folds every set of places with the same English and the same translation in
  all 17 locales into this module, writes the aliases, the langs sources, the recipes and `depends=`; then
  `python3 apps/i18n/gen.py --write --only strings` and `python3 tools/i18n/share.py known`.
- `python3 tools/i18n/catalog.py validate`: every alias resolves; `catalog.py adopt APP --check`: APP keeps no copy.

A new text: if it exists here (same English AND the same meaning), alias it; never add a second copy to an app.
